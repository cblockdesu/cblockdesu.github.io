cBlock ​

cBlock is a browser extension that hides Chinese content on any website.

Install ​

ChromeFirefox

Permissions ​

PermissionUse
storageStores cBlock’s settings and the results of website lookups
activeTabLets the popup find the current tab and its website
declarativeNetRequestBlocks access to China-linked websites
http://*/*, https://*/*Finds and hides Chinese content on all websites

How cBlock works ​

cBlock uses the four methods below to hide Chinese content and block connections to China-linked websites. For details, see How cBlock Decides.

MethodWhat it does
Text filterHides Chinese text and links to China-linked websites
Name filterHides items that mention a China-linked company or product (off by default)
Website scriptsChecks sellers, developers, and more that text alone can’t tell, website by website, and hides them
Domain blockBlocks China-linked websites before they load

China-linked websites are websites of companies founded or based in China, and websites whose domain ends in .cn, .中国, or .中國.

Website lookups ​

  • All are off by default.
  • When turned on, cBlock asks the website you’re on about sellers, developers, authors, and more, to tell more accurately whether they’re based in China.
  • See the Privacy Policy for details.
  • The X and pixiv lookups use private APIs, so the website may restrict your account. Use them at your own risk.
WebsiteWhat cBlock asksWhat it hides
AmazonSeller’s address, phone, and nameProducts by sellers based in China
SteamGame’s developer and publisherGames by studios based in China
XAuthor’s account location and connection sourcePosts by accounts based in China
pixivArtist’s profileWorks by artists based in China

Mode per website ​

  • You can set a mode per website. Enter one website and mode per line.
  • Set the mode to one of these four:
    • hide
    • blur
    • mark
    • empty
  • Websites not in the list use the default mode.
text
youtube.com hide
news.yahoo.co.jp blur
news.example.com mark

cBlock runs on a listed website even if it is turned off on the parent domain. The more specific domain wins, so in the example above, news.example.com runs with mark even if example.com is in Websites to turn off below.

Websites to turn off ​

Enter one website per line where cBlock should not run. In the example below, www.example.com is turned off too.

text
example.com
