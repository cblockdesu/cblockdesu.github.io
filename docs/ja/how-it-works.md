# 判定のしくみ

cBlockは次の4つのしくみで中国語・中国系のコンテンツを見つけて非表示にします。判定はすべてブラウザの中で行います。

| しくみ                                          | 判定に使うもの                                         |
| ----------------------------------------------- | ------------------------------------------------------ |
| [テキストフィルター](#テキストフィルター)       | ページの文字と中国系Webサイトへのリンク                |
| [名称フィルター](#名称フィルター)               | 中国系の企業や製品の名前                               |
| [Webサイト別スクリプト](#webサイト別スクリプト) | 出品者、ゲームの開発元、投稿者、作者、ページ自体の文字 |
| [ドメインブロック](#ドメインブロック)           | 開こうとしているページのドメイン                       |

## 中国系の企業とWebサイト

中国系の企業は次のいずれかに当てはまる企業です。登記した国は問いません。

- 中国本土で創業した企業
- 経営や開発の主な拠点が中国本土にある企業

中国の企業から出資を受けているだけの企業は含めません。対象は中国本土だけで、香港とマカオの企業や出品者、アカウントは含めません。ただし、中国本土の電話番号や接続元などの手がかりがあれば含めます。

中国系Webサイトとは、中国で創業した企業や中国を拠点とする企業のWebサイトと `.cn`、`.中国`、または `.中國` ドメインのWebサイトです。

## テキストフィルター

設定の「中国語のテキスト」と「中国系Webサイトへのリンク」で動作します。どちらも初期設定でオンです。

### 読み取る文字

- ページに表示されている文字
- 画像の代替テキスト（`alt`）、ツールチップ（`title`）、読み上げ用のラベル（`aria-label`、`aria-description`）

次の要素の中の文字は読みません。

- 入力欄（`input`、`textarea`）と編集できる欄（`contenteditable`）
- プログラムのコード（`code`、`pre`）
- スクリプトとスタイル（`script`、`style`）、ページの情報（`head`）

### 中国語の判定

段落やリスト項目のような文字のまとまり（以下、ブロック）ごとに次の順で判定します。

1. 漢字を含まないブロックは中国語と判定しません。
2. ページが `lang="zh-TW"` で台湾の中国語と示している部分は中国語として扱いません。
3. ページが `lang="zh-CN"` のように中国語と示している部分は中国語とします。
4. 仮名（ひらがな、カタカナ）を含むブロックは日本語とします。ただし、仮名で区切った部分のどれかに日本語にない漢字が2種類以上あれば中国語とします。
5. 仮名を含まないブロックは、次のいずれかに当てはまれば中国語とします。
    - 日本語にない漢字が1字以上ある（例: 们、这、说）
    - 中国語でよく使い、日本語ではほとんど使わない字や語がある（例: 很、什麼、沒有、有限公司）
    - 漢字が10種類以上あり、そのうち2種類以上が第1水準漢字ではない（例: 國、體）

> 「日本語にない漢字」は、日本語の文字コード（JIS X 0208、JIS X 0212、Shift_JIS）にない漢字です。「第1水準漢字」は、JIS X 0208のうち日常よく使う2,965字です。

### 繁体字の判定

「繁体字の中国語を表示」をオンにすると、中国語と判定したブロックのうち簡体字のものだけを非表示にします。初期設定ではオフです。

1. ページが `lang` で繁体字（`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO`）と示していれば繁体字とします。
2. 簡体字（`zh-Hans`、`zh-CN`、`zh-SG`）と示していれば簡体字とします。
3. どちらも示していなければ字で見分けます。繁体字だけで使う字があり、簡体字だけで使う字がなければ繁体字とします。
4. それ以外は簡体字とします。両方の字を含むブロックと、どちらも含まないブロックが当てはまります。

| 字の種類           | 条件                                           | 例         |
| ------------------ | ---------------------------------------------- | ---------- |
| 簡体字だけで使う字 | GB2312にあり、Big5と日本語の文字コードにない字 | 们、这、说 |
| 繁体字だけで使う字 | Big5の常用字にあり、GB2312にない字             | 們、這、說 |

> GB2312は中国本土の文字コード、Big5は台湾と香港の文字コードです。

### 非表示にする範囲

- 中国語と判定したブロックを含む投稿、カード、リスト項目を非表示にします。
- 2,000字を超えるブロックは判定しません（ページの大部分を非表示にしないため）。
- レイアウトを崩さないよう、次のWebサイトでは非表示にする単位をWebサイトごとにあらかじめ設定しています（例: YouTubeの動画1本、検索結果の1件）。
    - YouTube、Reddit、X、TVer、pixiv、Wikipedia、Yahoo!ニュース、楽天市場、GitHub、Hacker News
    - Google（google.com、google.co.jp）、Bing、DuckDuckGo、Yahoo! JAPAN、Yahoo（米国）、Brave、Ecosia、Startpage
    - Impress Watch、ファミ通.com

### 中国系Webサイトへのリンク

表示中のWebサイト以外の中国系Webサイトへのリンクを周りのカードごと非表示にします。カードが見つからなければリンクだけを非表示にします。

### 言語を問わず非表示にするもの

「中国語のテキスト」がオンのとき、次のものも非表示にします。

| Webサイト | 非表示にするもの                                                                  |
| --------- | --------------------------------------------------------------------------------- |
| X         | 「中国語からの翻訳」（英語表示では「Translated from Chinese」）と表示されたポスト |
| TVer      | 題名が「中国ドラマ」「中国時代劇」「中国映画」「中国アニメ」「華流」で始まる番組  |

## 名称フィルター

設定の「中国系の企業や製品の名前」で動作します。初期設定ではオフです。

cBlockは中国系の企業や製品の名前の一覧（以下、名称一覧）を搭載しています。オンにすると、名称一覧にある名前が出てくるブロックをどのWebサイトでも非表示にします。

### 名前の照合

- 英字の名前は単語として照合し、大文字と小文字を区別しません。後ろに数字が続いても一致します（例: Qwen3）。
- 短い名前やほかの語と紛らわしい名前は、大文字と小文字まで同じときだけ一致します（例: TCL、BYD、ERNIE）。
- 仮名や漢字の名前は文の途中にあっても一致します（例: 原神）。

### ほかの意味もある名前

アリババやvivoのようにほかの意味もある名前は、同じブロックに次の手がかりがもう1つあるときだけ非表示にします。「アリババグループ」のように企業を指すとわかる名前は、手がかりがなくても非表示にします。

- 名称一覧にあるほかの名前（ほかの意味もある名前を除く）
- 中国を表す語（中国、中華、China、Chinese）
- その企業に関わる語（例: アリババなら「決算」「株価」「ジャック・マー」）

## Webサイト別スクリプト

ページの文字だけではわからないことをWebサイトごとの方法で調べます。

- 「Webサイトへの問い合わせ」はWebサイトごとにオンにでき、初期設定ではすべてオフです。
- 問い合わせは画面内とその少し先にある項目についてだけ行います。
- 問い合わせの結果はブラウザに30日間保存し、同じ問い合わせを繰り返しません。
- Webサイトがエラーを返したときは一定期間（5分以上）問い合わせを停止します。

### Amazon

商品名に名称一覧の中国系ブランド名があれば、その商品を非表示にします。商品ページではページ本体を非表示にします。

- amazon.co.jp、amazon.com、amazon.co.ukで動作します。
- 商品名の中の名前はブランド名を指すため、[ほかの意味もある名前](#ほかの意味もある名前)も手がかりなしで非表示にします。
- 検索結果の絞り込み欄にある中国系ブランドの項目も非表示にします。

::: info 「Webサイトへの問い合わせ」がオンのとき
出品者の情報ページを読み、次のいずれかに当てはまる出品者の商品を非表示にします。

- 住所の国が中国（`CN`）
- 電話番号が中国の国番号（+86）で始まる
- 運営責任者名（amazon.co.jp）の表記がピンイン（中国語のローマ字表記）か中国語
- 販売業者名の表記が中国語か、ピンインの「有限公司」（youxian gongsi）
- 登録番号（amazon.co.uk）が中国の統一社会信用コードの形式

> - 住所が台湾、香港、マカオの出品者には、名前と登録番号による判定を使いません。
> - 出品者の名前の判定には「繁体字の中国語を表示」を適用しません。
> - 判定済みの出品者は絞り込み欄の項目も非表示にします。
> - Amazonが確認画面（CAPTCHA）を出したときは問い合わせを10分間停止します。
:::

### Steam

開発元かパブリッシャーが中国系のスタジオのゲームを非表示にします。「Webサイトへの問い合わせ」がオフのときはゲームのページだけを非表示にします。

- 社名の「Ltd.」のような語尾は無視し、残りが完全に一致したときだけ非表示にします。
- 中国の企業から出資を受けているだけのスタジオは含めません。

::: info 「Webサイトへの問い合わせ」がオンのとき
検索結果、トップページ、カテゴリーやキュレーターのページにあるゲームのカードも非表示にします。カードのゲームごとに開発元とパブリッシャーをSteamに問い合わせます。
:::

### X

中国政府の省庁と報道官、大使館、領事館、大使、国営メディアとその編集者など、決まった約50のアカウントのポストを非表示にします。

::: info 「Webサイトへの問い合わせ」がオンのとき
テキストフィルターが表示したポストのうち、次のポストの投稿者を調べます。

- `lang` が中国語のポスト
- 漢字があって仮名がないポスト

Xの「このアカウントについて」で調べ、「アカウントの所在地」か「接続元」が中国なら、その投稿者のポストをすべて非表示にします。

> Xの問い合わせ回数の上限（15分あたり50件）が残り5件になると、上限が戻るまで問い合わせを停止します。
:::

### pixiv

作品か作者が下の基準に当てはまれば、その作品や作者のカードとコメントを非表示にします。作品ページと作者のプロフィールページではページ本体を非表示にします。

作品は次の順で判定し、中国語なら非表示にします。

1. 小説の言語が中国語（台湾の中国語を除く）なら中国語とします。言語を表すタグ（中国語、中文、简体中文）がある作品も同じです。
2. 題名が中国語なら中国語、仮名を含めば日本語とします。
3. 題名でわからなければ、中国語のタグが仮名を含むタグより多いとき中国語とします。

作者は次のように判定します。

- 同じ作者の作品が2件以上表示され過半数が中国語なら、その作者の作品をすべて非表示にします。
- プロフィールページでpixivが読み込んだプロフィールが次のいずれかに当てはまれば、その作者の作品を非表示にします。
    - 地域が中国
    - 自己紹介が主に中国語で、地域が香港、マカオ、台湾ではない
    - 中国系Webサイトへのリンクか中国系のメールアドレス（例: @qq.com）があり、自己紹介が主に日本語ではない
- プロフィールに載せたXアカウントがXの問い合わせで中国と判定済みなら、その作者の作品を非表示にします。

> 中国語の行が仮名を含む行より多いとき、自己紹介を「主に中国語」とします。

::: info 「Webサイトへの問い合わせ」がオンのとき
プロフィールページ以外でも表示中の作品の作者のプロフィールを取得し、上の基準で判定します。
:::

### GitHub

「中国語のテキスト」がオンのとき、ページ自体の文字が中国語ならページ本体を非表示にします。

- リポジトリは説明で、issue、プルリクエスト、ディスカッションは題名で判定します。
- リポジトリのトップページではREADMEの行の半分を超えて中国語のときも非表示にします。英語のREADMEに「简体中文」のリンクが1行あるだけでは非表示にしません。
- 検索結果、一覧の行、コメントはテキストフィルターで1件ずつ非表示にします。

## ドメインブロック

設定の「中国系Webサイトのページをブロック」で動作します。初期設定でオンです。

- 中国系Webサイトのページを読み込む前にブロックします。ページに埋め込まれた別のページ（フレーム）もブロックします。
- 画像やスクリプトはブロックしません。
- ドメインの末尾で判定します。`bilibili.com` と `www.bilibili.com` はブロックしますが、`bilibili.com.example.org` はブロックしません。
- `.cn`、`.中国`、または `.中國` のWebサイトはすべてブロックします。`example.cn` はブロックしますが、`example.cn.com` や `cn.bing.com` はブロックしません。
- ポップアップでWebサイトをオフにしても、ブロックは続きます。止めるにはこの設定かcBlock自体をオフにします。

## 判定の限界

- 台湾、香港、マカオの繁体字も初期設定では非表示にします。`lang="zh-TW"` と示した部分だけは表示します。
- 「繁体字の中国語を表示」をオンにしても、文字だけでは台湾の文と香港の文を見分けられません。
- 珍しい漢字（例: 剝、幷）を使った日本語の文を誤って非表示にすることがあります。特に仮名を含まない短い文で起こります。
- 日本語の文字コードにある漢字だけで書いた短い中国語（例: 原神官網）は、非表示にしないことがあります。
- 英語やピンインで書いた中国のページは、ドメインがブロックの対象でなければ非表示にしません。
- 中国を拠点とする企業やアカウントが日本語や英語で書いた文は、テキストフィルターでは見分けられません。
