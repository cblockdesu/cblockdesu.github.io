# 中国系の企業

cBlockに組み込まれた[中国系の企業](/ja/how-it-works#中国系の企業とwebサイト){target="_blank"}の一覧です。

- **Webサイト**: サブドメインを含めて、[ドメインブロック](/ja/how-it-works#ドメインブロック){target="_blank"}と[中国系Webサイトへのリンク](/ja/how-it-works#中国系webサイトへのリンク){target="_blank"}の判定に使います。
